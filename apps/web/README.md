# @pearn/web

The Pearn app: Next.js static export, viem and any injected wallet (MetaMask) on Aurora. No server: the browser reads Aurora RPC and sends transactions from the wallet.

```sh
pnpm dev:local   # anvil + DevChain sample markets + next dev on :3000 (needs Foundry)
pnpm test        # unit tests: PayoutMath port, formatting, phases, create checks
pnpm e2e         # bet, resolve and claim in headless Chrome against anvil
pnpm build       # static site in out/
```

Point MetaMask at `http://127.0.0.1:8545` (chain 31337) and import an anvil test key to use `dev:local` by hand.

## Build-time env

| Variable | Default | |
|---|---|---|
| `NEXT_PUBLIC_CHAIN_ID` | `1313161555` | Aurora testnet; `1313161554` mainnet, `31337` local anvil |
| `NEXT_PUBLIC_MARKETS`, `NEXT_PUBLIC_ORACLE` | none | From `contracts/deployments/<chainId>.json`; without them the app says the contracts are not deployed |
| `NEXT_PUBLIC_STNEAR` | bridged stNEAR | Only needed on anvil |
| `NEXT_PUBLIC_RPC_URL` | the network's public RPC | |

## Layout

| Path | What |
|---|---|
| `app/` | Pages: markets, `market/?id=`, create, portfolio |
| `components/` | `layout/`, `markets/`, `market/` (bet, sponsor, position, resolve), `create/`, `portfolio/`, `ui/` |
| `hooks/` | Wallet, polled chain data, per-account position, transaction state |
| `lib/` | Config, reads (`chain.ts`), writes (`actions.ts`), `payout.ts` (PayoutMath port), formatting; `abi.ts` is generated by `pnpm abi` at the root |
| `e2e/` | Minimal CDP driver, local stack, the flow test |
