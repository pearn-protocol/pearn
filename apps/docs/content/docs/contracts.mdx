## PearnMarkets

| Function | Who |
|---|---|
| `createMarket(string question, uint64 closeTime, address resolver) → id` | anyone |
| `bet(uint256 id, Side side, uint128 amount)` | anyone, before close (approve stNEAR first) |
| `sponsor(uint256 id, uint128 amount)` | anyone, until resolved |
| `resolve(uint256 id, Outcome outcome)` | the market's resolver, after close and a post-close sync |
| `voidExpired(uint256 id)` | anyone, 7 days after close |
| `overrideInvalid(uint256 id)` | the guardian, within 24 h of resolution |
| `claim(uint256 id) → amount` | bettors and sponsors, after the window |

Views: `getMarket`, `positionOf`, `sponsorshipOf`, `claimable`, `hasClaimed`, `marketCount`.

Events: `MarketCreated`, `BetPlaced`, `Sponsored`, `MarketResolved`, `OutcomeOverridden`, `Claimed`. Every revert is a custom error with context, for example `RateStale(updatedAt)` or `ChallengeWindowOpen(id)`.
